📡 API Endpoints

1. Get Bundles
GET /api/bundles/ 
Headers:
  X-API-KEY: YOUR_API_KEY

Response:
{
  "status": "ok",
  "data": [
    {"id": 1, "name": "MTN 1GB", "price": "12.00", "network": "MTN"}
  ]
}
2. Sell Bundle
POST /api/sell/ 
Headers:
  Content-Type: application/json
  X-API-KEY: YOUR_API_KEY

Body:
{
  "bundle_id": 1,
  "recipient": "0540000000",
  "agent_username": "your_username"
}

Response:
{
  "status": "ok",
  "message": "Transaction initiated",
  "transaction_id": "TX123456"
}
3. Agent Transactions
GET /api/agent/<user_id>/tx/ 
Headers:
  X-API-KEY: YOUR_API_KEY

Response:
{
  "status": "ok",
  "data": [
    {"id": 10, "bundle": "1GB MTN", "recipient": "054...", "amount": "12.00"}
  ]
}
