RichDataBundles API Documentation

1. List Bundles

GET /api/bundles/

Returns all available bundles:

Headers:
  X-API-KEY: your-key
Response:
{
  "status": "ok",
  "data": [
    {"id": 1, "name": "MTN 1GB", "code": "mtn_1gb", "price": "100", ...}
  ]
}

2. Sell Bundle

POST /api/sell/

Headers:
  X-API-KEY: your-key
Body:
{
  "bundle_id": 1,
  "recipient": "024xxxxxxx",
  "agent_username": "agent01"
}
Response:
{
  "status": "ok",
  "authorization_url": "https://paystack.com/..."
}

3. Agent Transactions

GET /api/agent/{user_id}/tx/

Headers:
  X-API-KEY: your-key
Response:
{
  "status": "ok",
  "user": "agent01",
  "data": [ ...transactions... ]
}
