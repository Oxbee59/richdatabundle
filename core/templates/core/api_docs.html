📡 API Endpoints

1. Get Bundles
GET /api/bundles/ 
Headers:
  X-API-KEY: YOUR_API_KEY

Response:
{
  "status": "ok",
  "data": [
{% for b in bundles %}
    {"id": {{ b.id }}, "name": "{{ b.name }}", "code": "{{ b.code }}", "price": "{{ b.price }}", "network": "{{ b.network }}"},
{% endfor %}
  ]
}
2. Sell Bundle
POST /api/sell/ 
Headers:
  Content-Type: application/json
  X-API-KEY: YOUR_API_KEY

Body:
{
  "bundle_id": 1,
  "recipient": "0540000000",
  "agent_username": "your_username"
}

Response:
{
  "status": "ok",
  "message": "Transaction initiated",
  "transaction_id": "TX123456"
}
